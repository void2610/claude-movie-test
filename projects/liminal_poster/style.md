# liminal_poster スタイル

## 参照
- LiminalPalette の README のヒーロー画像 (暗い地に「+」の格子、青の「>」、黄色のカーソル、等幅のコード)
- motionpromptgallery の上位作品「動く街頭ポスター」: パレットを 3〜4 色に固定し、衝撃のコマでだけ版ずれさせる

## 色 (これ以外の色を使わない)
| 役割 | 値 |
|---|---|
| 背景 | #0E0E11 |
| 文字・面 | #ECECEF / パネル #1C1C21 |
| 主色 (経路・選択) | #3B82F6 |
| アクセント (属性・「同じコマンドに届いた」瞬間にだけ) | #FACC15 |

## 書体
- 見出し: sans (Mona Sans) wght 900 / wdth 112。左下に寄せ、画面からはみ出させる (中央に置かない)
- コード・ラベル: sans-mono
- サイズは 3 階層 (見出し 150 / 中 40 / ラベル 22)

## 動き (motion.rules)
| 要素 | 種類 |
|---|---|
| 候補の並び替え・チェック | micro |
| パネル・コードのカード | panel |
| 見出し | headline |
| カメラ | camera (活発さ 2: 1 ショットに遅い回り込みを 1 回まで) |

## 質感
- グレイン弱め、ビネット弱め
- 3 経路が属性に届くコマだけ、青と黄の版ずれ (misregister) を 3〜4px

## 避ける定番
- 中央の大きな文字、背景のグラデーション、全要素の同時フェードイン、最後に唐突なロゴ
- 0 フレーム目が暗いだけの画面 (ループの頭がサムネになる)
