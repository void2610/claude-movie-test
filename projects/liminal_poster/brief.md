# liminal_poster ブリーフ

## 一文
視聴者に残したいこと: `[LiminalCommand]` を 1 回書けば、人も AI もテストも同じコマンドを呼べる。

## 観客と場所
- 観客: Unity で開発している個人・小規模チームの開発者。デバッグコマンドを毎回 UI から作るのが面倒な人
- 載せる場所: X (タイムラインで止まってもらう)。README の冒頭にも貼れる
- 尺: 12 秒 (最初と最後のコマが一致するループ)
- 形式: 1:1 (1080x1080)

## 素材 (実物だけを使う)
- ロゴ: README のヒーロー画像の「>」+ 黄色のアンダースコア、ワードマーク「Liminal」白 +「Palette」青
- 画面: README に載っている実際の表記だけを使う (検索欄「> player health set」、候補「Player/Health/Set」、コード `[LiminalCommand("Player/Health/Set")] public void SetHealth(int value)`、HTTP の `POST /api/v1/execute`、テストの `await Execute("Player/Health/Set", 50)`)
- 色と書体: ヒーロー画像に合わせる (style.md)
- 音楽・効果音: エンジンで合成する

## 守ること・避けること
- 守る: 「1 つの属性 → 3 経路」の構造が 1 枚の絵で分かること
- 避ける: 中央の大きな文字 + グラデーション背景 + 全部フェードイン + 最後にロゴ、という定番
- 実在しない機能・数値 (速度・利用者数など) を出さない

## 納品物
動画 (1:1、ループ)、ポスター用の 1 コマ、レビューシート、ソース
