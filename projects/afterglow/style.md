# afterglow スタイル

## 参照
- lo-fi hip hop / chillhop の作業用 BGM の文法: 80 BPM 前後、9th・13th の和音、ブラシと生ドラム、エレピ、雨音
- J-POP の「エモい」和声: 丸サ進行 (Just the Two of Us 進行) と王道進行。真似するのは進行の機能で、既存曲のメロディは使わない

## 音 (値で決める)
| 項目 | 値 |
|---|---|
| テンポ | 80 BPM (1 小節 = 3.0 秒) |
| 調 | D♭ メジャー (A 区間は丸サ進行、B 区間は王道進行) |
| 跳ね | 16 分の裏を 58% の位置に (+31ms) |
| 後ろノリ | スネア +18ms、サックス +12ms (フレーズの頭はさらに 0〜20ms)、鍵盤は和音を低い音から 9ms ずつずらして弾く |
| エレピ | Surge XT `Vospi/Keys/EP Middle` (CLAP の「エレピ」z 2.8、候補 20 本の 1 位) |
| ベース | Surge XT `Basses/E-Bass` (「ベースギター」z 3.4、候補 12 本の 1 位) |
| パッド | Surge XT `Pads/MKS-70 Warm Pad` を 1 オクターブ上で (曲の和音で 16 通りを比べ、「夢のよう」3.5・「温かいパッド」3.9・チップチューン 0.8 で 1 位。単体の試聴で 1 位だった `Pads/Still` は曲の中ではシンセのリード・チップチューンに聞こえて最下位) |
| メロディ | 録音のサックス (「サックス」z 3.9〜5.1)。各音の実測の音程に合わせて再生速度を決める (サンプルは +11〜+41 セント高い) |
| サックスの表情 | 実音は音程 ±2〜5 セント・音量も一定でまっすぐなので、1 音ごとに動かす。ビブラートは 0.3 秒遅れて深くなり、深さ ±5〜14 セント (v で 1.4 倍)・速さ 4.8〜5.7Hz を揺らがせ、0.8dB の音量の揺れを伴う。s は 70〜120 セント下から、f は終わり 0.22 秒で 300 セント落とす、g は半音下の装飾音。短い音の並びはおよそ 3/4 をスラー (アタックを飛ばし 30ms で重ねる)。長い音は膨らんでから引き、強弱 60 で 3.2kHz・80 で 6.8kHz まで暗くする |
| 旋律 | A2〜D♭4 の 17 半音。2 小節の問いと答えで息継ぎし (休み 19%)、3 連符・食いを混ぜる。同じ音型は移して使い (12 小節目の型を 14 小節目で 5 度上に)、フレーズの終わりを毎回下りで F に着けない |
| ドラム | Gretsch のキック・スネア・ゴースト・クローズドハット・ライド |
| テープの揺れ | 鍵盤に Chorus (0.5Hz、深さ 0.12 = ±6.5 セント、原音なし) |
| 高域 | 鍵盤 5.5kHz、ドラム 9kHz、サックス 6kHz で切る。ドラムは 24kHz に落として戻す (粗さ) |
| ラウドネス | -14 LUFS、真のピークは -1dBTP 以下 |
| 環境音 | 窓の雨 (イントロは -30dB、曲中は -38dB)。最後は雨上がりの屋外に替える |

## 区間ごとの足し引き
| 区間 | 鳴るもの |
|---|---|
| intro | 雨・こもったエレピ (700Hz で切る。隣の部屋で鳴っている距離) |
| a1 | ドラム・ベースが入り、エレピのこもりが開く。メロディはエレピの上の音だけ |
| b1 | 王道進行。サックスとパッドが初めて入る |
| brk | ドラムが抜け、ハットだけ残る。サックスは長い音だけ |
| a2 | 全部。サックスが A の旋律 (フック) を吹く |
| outro | ドラムが抜け、エレピが再びこもる。IV△9 で止めて解決しない。雨が上がる |

## 書体
- 和音の名前: sans wght 300。♭・♯・△ だけ jp で、全角の字幅ではなくインクの幅で詰める (sans に字形が無い)
- 区間・進行の名前: mono

## 避ける定番
- 4 小節を同じ形で繰り返すだけのループ (区間ごとに鳴るものと、ドラムの細部を変える)
- 全部の音が拍の真上で同じ強さ
