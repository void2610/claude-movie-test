# bluehour スタイル

## 参照
- チルウェーブ / ダウンテンポのエレクトロニカの文法: 浅い残響のアルペジオ、ゆっくり開くフィルタ、キックで息をするパッド、TR-808 のリムショット
- Strudel / TidalCycles のライブコーディングの見せ方: 鳴らしているパターンの文字列を画面に出し、鳴った語を光らせる。休んでいる行はコメントアウト (`//`) して薄く残す

## 音 (値で決める)
| 項目 | 値 |
|---|---|
| テンポ | 90 BPM (1 小節 = 2.67 秒)。100・110・118 (4 つ打ち) も試したが、CLAP の印象 (トラップ・ヒップホップ寄り) はほとんど変わらず、遅いほうがチル |
| 調 | F。intro・a・outro は F△9 と G/F を 2 小節ずつ (リディアンで浮いたまま解決しない)、b・c は Dm9–B♭△9–F/A–Csus2、ブレイクは同じ進行を倍の遅さで |
| 跳ね | 16 分の裏を 8 分の 55% の位置に (+17ms)。ハットとシェイカーが揺れる程度 |
| パッド | Surge XT `Pads/Verb Pad` (単体の試聴で 18 本の 1 位。「温かいアナログのパッド」4.4) |
| アルペジオ | Surge XT `Plucks/Sinus Verby Pops`。曲の中で 11 本を比べて 1 位。最初の `Plucks/Friendly` は単体で「陽気なウクレレ」3.0 に聞こえ、曲全体を「企業の BGM」3.3 にしていた |
| リード | Surge XT `Leads/Butter`。重なった音だけ 70.8ms で滑らせる (Mono・Fingered Portamento) |
| サブベース | Surge XT `Basses/Smoothie` (「深いサブベース」4.1)。3+3+2 の 8 分 |
| ドラム | TR-808 のキック (`808bd:3` = BD0050、減衰 0.4 秒)・リムショット (`808:5`)・クローズドハット (`808:1`)・オープンハット (`808oh:2`)、DrumTraks のカバサ (`drumtraks:0`)。`808hc` はハットではなくハイコンガ |
| サイドチェイン | キックでパッドを -6dB (0.35 秒で戻る)、アルペジオ -3dB、ベース -4dB |
| フィルタの時間変化 | パッド: 380Hz → a の頭で 3.2kHz → ブレイクで 900Hz まで閉じ → c の頭で 4.2kHz → 終わりに 1.4kHz。アルペジオ: 入りの 500Hz → 5.5kHz、ブレイクで 700Hz → c の直前に 6kHz |
| 残響 | アルペジオとリードに 3/16 小節 (付点 8 分) のディレイ |
| 音量 (b の区間) | リード -16・パッド -17・ベース -17・アルペジオ -19・キック -20・リム -26・ハット類 -27 LUFS |
| ラウドネス | -14 LUFS、真のピークは -1dBTP 以下 |
| 環境音 | 夜の虫の声 (-39dB、a の途中まで)、明け方の森の鳥 (-36dB、outro) |

## 区間ごとの足し引き
| 区間 | 鳴るもの |
|---|---|
| intro | 虫の声・こもったパッド。5 小節目からアルペジオがこもったまま入る |
| a | キック・リム・ハット・シェイカー・サブベース。パッドとアルペジオが開ききる |
| b | 和音が動き出し、リードの問い (4 小節) と答え (4 小節)。リムに残響 |
| brk | キックとリードが抜け、同じ進行を倍の遅さで (パッドは 2 小節ずつ、アルペジオは 4 分音符)。後半からベースの全音符 |
| c | 全部。リードは b より高い音域の別の旋律。オープンハットが足される |
| outro | パッドとアルペジオとベースだけ。F△9 を 2 小節伸ばし、最後の 2 小節でマスターを -8dB、-40dB と下げて消す。鳥の声 |

## 書体
- すべて mono (Fragment Mono)。パターンの文字列は合字を切る (`<~` が矢印の記号にまとまるため)
- サイズは 3 階層: 区間と和音・題 (W×0.016)、コード (W×0.0135)、補足 (W×0.013)

## 動き
- 画面の動きは「鳴った語が光って 0.12 秒〜音の長さで戻る」と、行の明るさの切り替え (0.35 秒) だけ。カメラは動かさない
- 空の色は区間をまたいで連続して変わり、星は 50 秒から 100 秒にかけて消える

## 避ける定番
- 中央の大きな文字とグラデーションだけの画面 (画面の主役は実際に鳴っているコード)
- 4 小節を同じ形で繰り返すだけのループ (リードは 16 小節すべて違う。区間ごとに鳴るものとフィルタを変える)
- EDM のビルドアップ (スネアロール・ドロップ)
