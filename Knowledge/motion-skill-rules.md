# モーション技能リポジトリから得た規則 (2026-10-09)

出典の略記: WX = whaleyxbt/claude-motion (MIT) / KL = t3knobox/klik-anim-skill-creation (ライセンス表記なし。数値と考え方の参考にとどめ、文面は使わない) / LF = LottieFiles/motion-design-skill (MIT) / IA = iart-ai/motion-design-skills (MIT) / HW = howseen-ai/claude-motion-design (MIT)。以下はすべて要約・言い換え。

## 動き

- 方向でイージングを分ける: 登場は減速 (WX は cubic-bezier(0.16,1,0.3,1))、退場は加速、画面内の移動は加減速、ループは sine、回転や進捗だけ linear (WX・LF)
- 曲線は 1 か所で定義し、場面ごとに作らない (KL)
- ばねは「着地・ポップ」に、ベジェは「移動」に使う (KL)。減衰比は 0.72 以上にして漫画的な跳ねを避ける (HW)。大きく跳ねるばねは 1 本に 1 回 (WX)
- 尺は要素の重さで決める (30fps 換算): 微小な反応 4〜7f、小さな要素 10〜14f、パネル 17〜26f、シーン移動 24〜36f、カメラのフレーズ 48〜108f。迷ったら 2 割短くして収まりを足す (KL)。移動距離が長いほど長くする (LF)
- 退場は登場の 5〜7 割の長さ (WX・KL)
- 兄弟要素の時間差は 40〜120ms、グループ全体で 0.5〜0.8 秒以内 (LF・IA・KL)
- 0 倍からの拡大で登場させない。0.9〜0.97 倍 + 透明から (KL)
- 画面の 1/3 を超える移動は中間のキーを置く。同時に動くのは全体の 1/3 まで (LF・IA)

## 読ませる時間

- 1 行の最低表示時間 = max(0.7 秒, 0.25 秒 + 文字数 / 17) (KL)
- 短い句は 1 秒以上、最後の決め台詞は 2 秒以上 (WX)
- 動いている最中の文字を読ませない (WX)
- 静止画では長さを検証できないので、表示時間は計算で検査する (KL)

## カメラ

- 作品ごとにカメラの活発さを 1〜5 で決める。中程度以上なら、ズームだけの動きは避けて横移動か回転と組む (KL)
- ズームは対数空間で補間する (HW)
- 動きの終わりは完全停止ではなく、わずかな漂いに落とす (KL)
- 隣り合うシーンで同じカメラの動きを繰り返さない (KL)
- 視差の速度は、背景 0.1〜0.3 倍、中景 0.5〜0.7 倍、前景 1〜1.5 倍 (IA)

## 構図・文字・色

- 書体は 3 種まで、文字サイズは 3 階層まで。サイズは固定の比率で決める (WX・KL)
- 主役は 1 つ、副役は最大 1 つ。視覚的な中心は高さの 45〜48% (IA・KL)
- セーフエリア: 16:9 は端から 5% 以上。9:16 は上 12〜14%・下 18〜20%・左右 6%。1:1 は 6〜8% (KL・IA)
- 縦長版は切り抜きではなく再配置 (IA・HW。rari の記事とも一致)
- アクセント色は 1 色で、「変わったもの・答え」にだけ使う。パレット外の色を使わない (WX・HW)
- 色の補間は OKLCH か Lab で行う。sRGB で補間すると中間がくすむ (IA)
- 完全に止まった要素を作らない。わずかな漂いとグレインを残す (WX・KL)

## 避けるもの

- 全部が同時にフェードイン、全部が同じ尺 (WX・IA)
- 動き出しと止まりが linear (全員)
- 1 フレームに焦点が複数ある (WX)
- 0 フレーム目が真っ黒 (X ではサムネになる) (WX)
- 同じ演出の使い回し (KL)
- 退場 → 空白 → 登場のつなぎ。無関係な要素同士のクロスフェード (KL)
- 虹色のグラデーション、意味のない粒子や 3D フリップ、曖昧な「高級感」指示 (HW)
- 数値の捏造。説明用のデータには例示であることを明記する (HW)

## 検査の方法

- 動きのエネルギー: フレーム差分の時系列を約 1 秒で平滑化し、p10 / p50 / p90 から「静止の割合」(目標 40〜60%) と「起伏」(p90 - p10) / p50 (0.15 未満は平坦) を出す。グレインが底上げするので、ゼロではなく p10 を基準にする (KL)
- 1 フレームだけの破綻 (pops): フレーム n が前後と違うのに、n-1 と n+1 がほぼ同じなら、1 フレームの閃きと判定する (HW)
- ループ: 0 秒と終端 (と終端の 1 フレーム手前) を比べる (HW)
- 評価は 10 点満点で、最初の 2 秒、360px 幅での可読性、動き、変化の頻度 (2〜4 秒ごとに新しいこと)、構図、正確さ、音の同期を採点し、最悪の 3 点を時刻つきで直す (HW)
- 作り手とは別の文脈で判定する。フレームだけを見せて主張を言い直させ、言えなければ失敗 (HW・KL)

## 音

- 絵と音は同じタイムラインから時刻を引く。直書きしない (WX)
- riser は着地の直前で終わらせる。riser と impact は 1 本に 1 回ずつ (WX)
- 鋭い立ち上がりの音には鋭い動きを、ゆっくり膨らむ音には長い助走の動きを合わせる (KL)
- 主要な出来事は最大 0.15 秒まで音のキューに吸着させてよい (HW)
- 構造上のカットは小節頭か拍頭に、アクセントは 8 分のグリッドに置く。導入は長い間隔、クライマックスは 1〜2 拍、解決は長いホールド (IA)
