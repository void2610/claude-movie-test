# 反復の軌跡を見せる (2026-10-17 調査)

出典: @julianleiss の投稿 (2026-10-17)。ボルヘスの詩「Ajedrez」を元にした 52 秒・15 カットの縦長映像 (Opus 5.5 x-high・Paper で編集・Midjourney) を、どう作ったかを 32 秒の「反復の軌跡」の動画で見せたもの。動画は X の再生画面からコマを取り出して見た (ダウンロードはしていない)。

## 軌跡の動画の構成 (1 版 1 頁、28 版)

- 左上: 版の番号と、その版で何を試したかの名前 (「brief v4: 実物の画像だけ」「el poema en la grilla」「storyboard de julián」など)。数値: 書き出した回数 (v001〜v011)、書き出しの時間、形式 (1920x1080 / 1080x1080)、ファイルの大きさ、Paper のフレーム数、プロンプト数・ツール呼び出し数・書いた / 読んだトークン数
- 中央: その版のコマの一覧 (4×3 前後)
- 右: 系譜。縦に版を並べ、分岐・行き止まり (×)・合流 (破線) を線で描く。版ごとに、どの層 (texto / imagen / gráfico / … / sonido) が変わったかを点と線で示す列がある。今の版より後は薄く描く
- 下: その版のタイムラインの段 (texto の 14 の詩句・imagen・voz・foley・ambiente)
- 作品の作風: 灰色の紙に小さな等幅の文字、記録写真 (マイブリッジの馬・チェスの盤・手)、余白の多い編集的なレイアウト。詩句ごとにカットする

## このエンジンへの取り込み

- **版の記録** (`motion/trail.py`): 作品全体の `render` と `review` のたびに、`projects/<名前>/trail/` に版を 1 つ足す (git の管理外。reviews/ と同じ扱い)。`--note "..."` で何を試した版かを名前にする (無ければコミットの題か「未コミットの変更」)
  - 持つもの: 日時・コミット・形式・書き出しの時間・大きさ・エラー / 注意の数・引数・等間隔の 12 コマ・タイムラインの段
  - 変わった層: コード (作品の .py)・人の調整 (edits.json)・値 (tune.json)・文字 (見えている要素の名前の集合)・音 (効果音と環境音の時刻・録音・音量)・絵。絵は 12 コマを 16×9 の濃淡に縮めて (面積平均でグレインが消える)、差の平均が 4 (0〜255) を超えたら変わったとする。最初は差分ハッシュ (dHash) にしたが、暗い背景のグレインで同じ絵でも 256 ビット中 40 ビット前後が変わり、使えなかった
  - 行き止まり: コード・調整・値が、直前より古い版と同じに戻ったら、その間の版を試して捨てた版 (×) として描き、戻り先から破線を引く。liminal_poster では、文字の大きさの例外を足して外したコミット (f04c39e → 50cb1b7) が行き止まりとして出た
- **`motion trail projects/x`**: 版ごとの頁 (1920×1080) を並べた動画 (1 版 1.2 秒、最後は 3 秒) と、全版の一覧の画像を build/<名前>/ に書く。頁は投稿の構成に倣う (左: 名前と数値、中央: コマ、右: 系譜と変わった層の点、下: 段)
- **`--git`**: 記録を始める前の版を、作品を変えたコミットごとに一時的な git worktree で、その時点のエンジンの `sheet` で描いて足す (時刻の順に並べ直す)。liminal_poster の 10 コミットで 29 秒。git の外の素材 (assets/footage) は今のものを参照する
- **review のシートにタイムラインの段**: ショット・文字 (全コマの文字の検査のついでに、要素ごとに見えている区間を取る)・効果音 (見せ場は赤)・環境音・音楽 (音のある区間)。書き出しの版は文字を数えないので、中身が同じ直前のレビューの文字の段を引き継ぐ
- テストの書き出しやレビューは版として記録しない (`tests/conftest.py` で `MOTION_NO_TRAIL`)。記録すると fixtures の下にファイルが残る

## 見送ったもの

- **プロンプト数・ツール呼び出し数・トークン数**: エンジンからは見えない。Claude Code のセッションの記録を読めば取れるが、作品の外の個人的な記録を作品の履歴に混ぜることになるので入れない
- **系譜の分岐と合流 (案を並べて選ぶ `motion variants`)**: 案の書き出しは区間 (`--start` / `--end`) の下書きで、作品の版ではない。選んだ案は作品に取り込んだ後の書き出しで版になる。分岐として描くには案ごとの記録の形を決める必要があり、必要になったら足す
- **スタジオの中で軌跡を見る**: 動画と画像で足りる。スタジオに入れるなら「案」と同じく並べて再生する形になる
- **作風 (灰色の紙・等幅の小さな文字・記録写真)**: 作品ごとの style.md で決めることで、エンジンの既定にはしない。素材は実物だけを使う規則 (CLAUDE.md) のとおり、記録写真を使うなら出典のある実物を使う
